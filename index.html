Abstract

UniAfford studies generalizable 2D-3D affordance perception under a unified multimodal setting. Given language instructions, RGB images, and point clouds, the model learns to route MLLM hidden states into text, 2D, and 3D branches. Routed affordance tokens are used as task queries for downstream decoders, producing image masks and point-wise 3D affordance logits. This design supports flexible supervision across image-only, point-cloud-only, and paired multimodal samples.

Method Overview

Token Router

Soft branch assignment

The router predicts text / image / point-cloud probabilities for each MLLM hidden state. Supervision from <img_aff> and <pc_aff> anchors downstream affordance queries.

Similarity Alignment

Point-wise 3D decoding

Routed 3D affordance queries and per-point features are projected into a shared space, normalized, and matched with a learned logit scale.
